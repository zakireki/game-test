# Asteroid Dodge

A simple game built with C++ and SFML, where the player controls a spaceship and dodges falling asteroids.

⚠️ **This project is a Work in Progress**

## Current Features
- Ship control in four directions (WASD)
- Continuous random asteroid spawning
- Screen boundary detection (ship can't leave the window)
  - Collision detection between ship and asteroids
  - Add new ship 

## In Progress
- Scoring system
- Game Over screen

## Requirements
- SFML 2.x
- A compiler supporting C++11 or later

## How to Build
1. Make sure SFML is installed and linked to the project
2. Clone the repository
3. Ensure the `Assets` folder is placed next to the executable
4. Build and run

## Controls
| Key | Action |
|---|---|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
